# INK JUMP

Чёрно-белая аркада в духе «дудл-джампа» для **Telegram Mini Apps**. Прыгай по платформам как можно выше: чем выше, тем меньше платформ и больше шипов и врагов.

Чистый HTML + CSS + JavaScript (Canvas), без фреймворков и сборки.

## Возможности

- **Платформы:** обычные, движущиеся, одноразовые (ломаются после прыжка), невидимые (проявляются при приближении), с шипами
- **Усиления:** пружина, ботинки (10 с), щит (10 с, бессмертие кроме пропасти), ракета
- **Враги:** летают влево-вправо; прыжок сверху убивает, касание сбоку — конец игры
- **Комбо:** несколько убитых врагов подряд без касания платформы дают больше очков
- **Монетки:** копятся между забегами (+1 монета за каждые 50 очков)
- **Магазин скинов:** 8 героев в чёрно-белом стиле, цены от 40 до 600 монет, выбор и покупки сохраняются на устройстве
- **Версия для ПК:** на широком мониторе по бокам подсказки по управлению, `F` или кнопка — полный экран
- **Окружение:** каждые 300 очков меняется фон (клетка → точки → ночь со звёздами → диагонали)
- **Сложность** растёт с высотой
- Личный рекорд хранится на устройстве (`localStorage`)
- Русский и английский интерфейс (по языку Telegram / браузера)
- Адаптация под любые экраны, вибро-отклик через Telegram

## Управление

| Платформа | Управление |
|-----------|------------|
| Телефон | веди пальцем влево-вправо (палец «тянет» героя) |
| ПК | `A` / `D` или `←` / `→`, `P` или `Esc` — пауза, `Space` — старт |

## Запуск локально

```bash
python -m http.server 8000
# открой http://localhost:8000
```

Вне Telegram игра тоже работает — это обычная веб-страница.

## Публикация и подключение к Telegram

1. Выложи репозиторий на GitHub (секретов в проекте нет, токены не нужны).
2. Захости статику по **HTTPS**: GitHub Pages (`Settings → Pages → Deploy from branch`) или Cloudflare Pages (подключи репозиторий, build command пустой, папка — корень).
3. В Telegram открой **@BotFather**:
   - `/newbot` — создай бота;
   - `/newapp` — выбери бота, задай название, описание, картинку 640×360, вставь URL своей игры и короткое имя;
   - либо `/mybots` → твой бот → **Bot Settings → Menu Button → Configure menu button** и укажи URL.
4. Открой бота и нажми кнопку — игра запустится внутри Telegram.

## Структура

```
index.html   разметка, стили, экраны (меню, пауза, конец игры)
game.js      вся логика: физика, генерация уровня, отрисовка, ввод, Telegram SDK
README.md
```

## Настройка баланса

Все числа — в блоке `CONFIG` в начале `game.js`: сила прыжков, длительность усилений, высота, на которой сложность достигает максимума, шаг смены окружения.
